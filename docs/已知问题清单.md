# 已知问题清单

## 非阻塞限制

1. **交易日估算**：下一预测日期使用下一工作日，不包含法定节假日和临时休市；演示时必须说明。
2. **模型效果**：正式实验中单变量 LSTM 未优于 Naive，属于真实负结果，不得改写成“LSTM 精度更高”。
3. **特征范围**：当前主要使用日线价格和成交量/额，未加入宏观、基本面、新闻情绪等外部特征。
4. **泛化范围**：正式样本为 4 只股票、2018—2025 年，结论不能外推为整个市场的普遍规律。
5. **资源耗时**：正式多股票、多种子训练在 CPU 上较慢；答辩使用预训练资源，不现场重训。
6. **结果分发**：`data/` 和 `artifacts/` 默认被 Git 忽略，正式行情和阶段 8 结果需通过交付压缩包或移动介质单独携带。

## 已关闭的严重风险

- 未发现训练/验证/测试日期重叠。
- 未发现全量数据拟合 Scaler、测试集调参或测试样本参与 Early Stopping。
- 未发现窗口日期错位、目标日特征泄漏或错误反归一化。
- 未发现 Naive/MA 在预测前读取目标日真实值。
- 未发现不同目标日期直接比较、最后 epoch 冒充最佳模型。
- 未发现源码/配置中的真实 Token、密码、用户目录或固定盘符。
