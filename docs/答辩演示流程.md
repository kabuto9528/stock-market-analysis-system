# 5—8 分钟答辩演示流程

## 演示前准备

- 提前启动 Streamlit，并确认 `offline_demo_stage9` 已出现在实验列表。
- 关闭无线网络也能完成演示；不要现场运行正式训练。
- 预先打开 `docs/实验结果分析.md` 和正式图表目录作为备用。

## 0:00—0:45 系统介绍

- 说明任务：用截至 t 日的数据预测 t+1 日收盘价。
- 展示首页技术路线：数据 → 清洗/划分 → Scaler → 窗口 → 模型 → 公共日期评价。
- 强调系统仅用于教学科研，不构成投资建议。

## 0:45—1:45 数据加载与质量

- 数据获取页选择“离线演示”，点击加载。
- 指出标准字段、日期升序、重复日期处理和质量报告。
- 说明答辩现场不依赖 Token 或网络。

## 1:45—2:45 数据分析

- 展示 K 线、MA5/10/20、成交量和相关性热力图。
- 简述价格序列非平稳、高噪声和成交量波动特征。

## 2:45—3:30 加载模型

- 进入预测分析，选择 `offline_demo_stage9`。
- 说明加载时会校验特征列、input_size、窗口长度和 Scaler。
- 强调展示的是预训练测试资源，因此不需要现场长时间训练。

## 3:30—4:40 预测结果

- 展示真实值/预测值、逐日误差和 RMSE、MAE、DA、相对提升率。
- 解释 previous_close 与三分类 DA 定义；R² 不用于排名。

## 4:40—5:50 模型对比与实验结论

- 展示 Naive、MA、SES、ARIMA、单变量 LSTM 的公共日期对比。
- 说明多变量 LSTM 只作为特征消融，不混入传统模型主比较。
- 给出正式结论：单变量 LSTM 未优于 Naive；ARIMA 平均表现接近或略优于 Naive；多变量特征改善 RMSE 但 DA 不稳定。

## 5:50—6:40 正确性与可追溯性

- 展示 experiment_id、模型、Scaler、训练历史、逐日预测和 alignment 文件。
- 说明 Scaler 仅训练集 fit、验证集选最佳 epoch、测试集评价一次、所有模型取公共目标日期。

## 6:40—7:20 局限与展望

- 下一日期仅按工作日估算，尚未接入完整交易所日历。
- 当前以日线价量特征为主，未纳入宏观、新闻情绪和公司基本面。
- 股票高噪声使复杂模型不一定优于简单基线；后续可预测收益率/方向并使用滚动训练。

## 7:20—8:00 结束与提问

- 总结系统实现了可复现、无已知严重泄漏、可离线演示的完整闭环。
- 若被问“为什么窗口 60”，回答默认值约覆盖 3 个月交易历史；正式控制变量实验最终在验证集锁定窗口 30。
