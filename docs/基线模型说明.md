# 基线模型说明

## 1. 模型范围与公平比较

阶段 4 实现六种单变量传统基线：Naive、MA5、MA10、MA20、SES 和 ARIMA。
它们只使用 `close`，因此正式主对比只能与“仅使用 close 的单变量 LSTM”比较；六变量 LSTM
属于特征消融实验，不得混入同一张主对比表。

所有模型实现统一 `ForecastModel` 接口：

- `fit(train_data)`：只接受阶段 3 产生的 `train DataPartition`；
- `predict(data, target_dates, strategy=...)`：按指定目标日期回测；
- `get_params()`：返回可追溯构造参数；
- `model_name`：返回稳定模型名。

统一输出字段严格为：

`target_date、previous_close、actual、predicted、model_name`。

`run_baseline_suite` 强制所有模型使用相同训练分区、预测协议和 target_date 集合，并校验
日期、`actual` 与 `previous_close` 完全一致。

## 2. 无未来数据的执行顺序

滚动一步预测对每个目标位置固定执行：

1. 读取目标日之前已经实现的历史状态；
2. 生成目标日预测值；
3. 保存该日 `actual`；
4. 预测完成后，才允许使用该日真实 close 更新状态，为下一目标日服务。

因此模型不会在预测日期 `t` 时读取 `close[t]` 或任何更晚值。自动测试会把首个目标日及
其后的真实值改成极端大值，并验证首个预测保持不变。

模型拟合前还会确认预测行情的训练日期和训练 close 前缀与拟合数据完全相同，防止把模型
套到不一致的数据版本。目标日期必须严格升序、唯一、存在于行情中并晚于训练区间。

## 3. 六种模型

### 3.1 Naive

目标日预测等于目标日前最近一条已实现行情的真实收盘价：

`ŷ_t = close_(t-1)`。

它是方向准确率和相对 RMSE 提升率的重要参照，不是可以省略的“弱模型”。

### 3.2 MA5 / MA10 / MA20

目标日预测为此前最近 `k` 条已实现 close 的算术平均：

`ŷ_t = mean(close_(t-k), ..., close_(t-1))`。

训练历史少于窗口长度时直接报错。滚动一步模式只在完成本日预测后才把本日 actual 加入队列。
静态多步模式则递归使用自身预测补充未来窗口，不读取未来 actual。

### 3.3 SES

简单指数平滑状态更新为：

`level_t = α × close_t + (1-α) × level_(t-1)`。

`α` 可由配置显式给定，也可仅使用训练集估计。验证/测试期间固定 `α`，滚动协议只更新
水平状态，不重新使用验证或测试数据估计参数。静态多步预测保持训练结束水平不变。

### 3.4 ARIMA

默认使用有限固定阶数 `ARIMA(1,1,0)`，也允许构造时显式传入 `(p,d,q)`；不执行无边界
网格搜索。参数只在训练集估计。滚动一步预测通过 `append(..., refit=False)` 加入已经实现的
历史值，不重新拟合参数；静态模式直接从训练结束状态执行多步 forecast。拟合、预测或状态
更新失败时统一转换为包含模型名和原因的明确异常。

## 4. 两种预测协议

### rolling_one_step（正式比较默认）

每个目标日使用此前真实历史做一步预测。目标日真实值只能在该日预测完成后用于下一步。
该协议模拟每日收盘后更新、下一交易日前预测，Naive、MA、SES、ARIMA 均使用相同规则。

### static_multi_step

训练结束后一次性预测多个未来位置，整个预测区间不读取任何真实值：

- Naive：重复训练末尾 close；
- MA：递归加入自身预测；
- SES：重复训练末尾水平；
- ARIMA：调用固定训练结果的多步 forecast。

两种协议回答的问题不同，结果不得混在同一张模型比较表中。正式主实验默认使用
`rolling_one_step`，并在实验配置中保存协议名称。

## 5. 目标日期与日期缺口

目标日期应直接使用阶段 3 `WindowedSamples.target_dates`，保证与单变量 LSTM 的评价日期一致。
默认把上一条真实行情记录视为 `previous_close` 来源，不按自然日补造周末、节假日或停牌数据。

如果调用方拥有权威交易所开市日历，可传入 `expected_trading_dates` 启用严格连续性检查。
权威日历必须覆盖训练起止日期和全部目标日期；从训练起点到最后目标日之间缺少任一
预期开市日期，或行情含有日历之外的日期时，预测会失败并提示补充真实行情或丢弃受影响
样本；禁止用合成价格填补。

## 6. 异常与最少数据

- Naive 至少需要 1 条训练记录；
- MA 至少需要与窗口长度相同的训练记录；
- SES 至少需要 3 条训练记录；
- ARIMA 最少记录数由固定阶数计算，默认不少于 8 条；
- 非有限 close、乱序/重复日期、未拟合预测、训练前缀变化和字段缺失均立即报错。

阶段 6 将在统一结果上计算 RMSE、MAE、R²、DA 与相对 Naive RMSE 提升率；模型排名不得
依据 R²，而应依据 DA 与相对提升率。
