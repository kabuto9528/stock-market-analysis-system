# 评价与回测说明

## 1. 适用范围

阶段 6 只负责评价指标、统一测试集回测和实验产物管理。参数搜索与正式实验不在本阶段执行。主比较表只允许放入使用 `close` 的单变量 LSTM 与 Naive、MA、SES、ARIMA 单变量基线；六变量 LSTM 必须在阶段 8 的特征消融实验中单独报告。

## 2. 指标定义

设公共测试日期上的真实值为 `actual`、预测值为 `predicted`、目标日前一条真实交易记录收盘价为 `previous_close`，样本数为 n。

- RMSE：`sqrt(mean((predicted - actual)^2))`。
- MAE：`mean(abs(predicted - actual))`。
- R²：`1 - SSE/SST`；仅作为价格水平拟合度参考，不参与模型排名。真实值为常量时，完美预测记为 1，否则记为 0。
- DA：预测方向为 `sign(predicted - previous_close)`，实际方向为 `sign(actual - previous_close)`，两者符号一致的比例。
- 相对 Naive RMSE 提升率：`(naive_rmse - model_rmse) / naive_rmse * 100%`。正值表示优于 Naive，负值表示劣于 Naive；Naive RMSE 为 0 时该指标无定义并拒绝比较。

### DA 的平盘规则

方向使用三分类符号：`-1=下跌`、`0=平盘`、`1=上涨`。只有预测与实际符号完全一致才算正确。预测平盘但实际上涨/下跌，或预测上涨/下跌但实际平盘，均算错误；平盘不会被并入上涨或下跌。

## 3. 指标输入校验

`src/evaluation/metrics.py` 的公开指标统一检查：

1. `actual`、`predicted`、`target_dates` 与 `previous_close`（DA 时）长度一致；
2. 数值必须是一维且不含 NaN、正无穷或负无穷；
3. 日期必须可解析、无缺失、无重复并严格升序；
4. 默认至少 2 个样本；
5. 相对提升率要求两个 RMSE 为有限值，模型 RMSE 非负且 Naive RMSE 大于 0。

## 4. 统一测试集回测

`UnifiedTestBacktestService` 初始化时必须传入阶段 3 生成的测试集目标日期。每个模型预测表字段固定为：

`target_date、previous_close、actual、predicted、model_name`

服务执行以下步骤：

1. 拒绝任何不属于测试集的日期，防止验证集混入最终评价；
2. 检查每张表日期、数值、模型名和最少样本数；
3. 对模型日期集合取交集，在公共 `target_date` 上重新索引；
4. 检查公共日期上的 `actual` 与 `previous_close` 完全一致；
5. 记录预期测试日期、各模型原始日期、缺失预期日期、因取交集被排除日期和最终公共日期；
6. 以公共日期上的 Naive RMSE 计算所有模型的相对提升率；
7. 排名依次按 DA 降序、相对提升率降序、RMSE 升序，R² 不参与排序。

日期集合不一致时禁止直接比较原始指标，必须使用 `alignment.json` 中明确记录的公共日期重新计算。

## 5. 验证集与测试集隔离

- Scaler 只在训练集拟合。
- LSTM 固定配置在训练集优化，只用验证集 Early Stopping 并恢复最低验证损失权重。
- 基线统计参数只在训练集拟合；滚动到测试期前可以按时间顺序接收已经实现的验证期真实观测更新状态，但不得重新用测试集选择参数。
- 测试目标只在模型和参数固定后运行一次最终评价。
- `ExperimentRecord` 固定记录 `evaluation_partition=test`、验证集用途和 `test_evaluation_count=1`。

## 6. 实验记录与产物

每次实验目录为 `artifacts/experiments/<experiment_id>/`，至少保存：

- `experiment_record.json`：实验总记录，包括 experiment_id、时间、股票代码、数据区间、集合边界、特征、窗口、模型参数、随机种子、指标、耗时、状态和产物路径；
- `experiment_config.json`：不含预测结果的实验配置与测试隔离声明；
- `metrics.json` / `metrics.csv`：公共测试日期上的指标；
- `daily_predictions.csv`：所有模型在公共日期上的逐日预测；
- `model_comparison.csv`：按 DA、相对提升率和 RMSE 生成的比较表；
- `alignment.json`：日期交集及排除记录；
- `selected_lstm.pt`、`selected_lstm.scaler.json`、`training_history.json`：固定 LSTM、Scaler 和训练历史。

实验状态使用 `started/completed/failed` 字段；当前保存最终指标的流程要求状态为 `completed`。`result_kind=test` 表示自动测试或固定小样例，不能作为论文正式结论；阶段 8 正式运行才使用 `formal`，并仍需审查数据和配置。

## 7. 命令行

```powershell
python scripts/run_experiment.py `
  --file data/example.csv `
  --ts-code 600000.SH `
  --result-kind test `
  --device auto
```

脚本一次运行 Naive、MA5、MA10、MA20、SES、ARIMA 和固定单变量 LSTM。默认结果标记为 `test`，避免阶段 6 小样例被误认作正式实验。脚本不进行无边界参数搜索，也不运行多变量 LSTM 主比较。

## 8. 固定小型样例

`tests/fixtures/stage6_small_market.csv` 与 `stage6_test_config.yaml` 是确定性自动测试夹具，仅用于验证端到端链路。其输出必须带 `result_kind=test` 和“不是正式实验结论”的提示；样例指标不得写入论文正式结果表。
