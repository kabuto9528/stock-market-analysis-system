# 安装说明

## 1. 环境要求

- Python 3.12（最终验收环境为 Python 3.12.6）
- 建议内存 8 GB 以上；离线样例和自动测试可仅使用 CPU
- 正式多股票训练建议使用 CUDA GPU，但不是系统启动和答辩演示的前提

## 2. 创建环境

```powershell
Set-Location <项目目录>
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

若 PowerShell 阻止激活，可仅对当前终端执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

## 3. 安装依赖

CPU 或已正确配置 PyTorch 的环境：

```powershell
python -m pip install -r requirements.txt
python -m pip check
```

GPU 环境应先根据本机显卡驱动和 CUDA 安装匹配的 PyTorch，再执行 `requirements.txt`。不要盲目复制其他机器的 CUDA 安装命令。

验证关键依赖：

```powershell
python -c "import torch, pandas, sklearn, statsmodels, streamlit; print(torch.__version__, torch.cuda.is_available())"
```

## 4. 可选 Token

```powershell
Copy-Item .env.example .env
```

把真实 Token 仅写入 `.env`。不得写入源码、YAML、日志、截图或论文附件。无 Token 不影响 CSV、缓存、离线资源和预训练模型演示。

## 5. 安装验收

```powershell
python -m pytest -q -p no:cacheprovider --basetemp artifacts/test_tmp
python -m streamlit run app.py
```

若默认临时目录出现权限错误，保留项目内 `--basetemp` 参数。若端口占用，可追加 `--server.port 8765`。

## 6. 离线资源

- 行情：`demo/offline_market.csv`
- 预训练模型：`demo/offline_demo_stage9/selected_lstm.pt`
- Scaler：`demo/offline_demo_stage9/selected_lstm.scaler.json`
- 实验指标与逐日预测：同一目录内 JSON/CSV

这些资源标记为 `test`，仅用于功能演示，不作为论文正式实验结论。
