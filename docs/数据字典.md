# 数据字典

## 1. 通用约定

- 运行环境：Python 3.12。
- 日期字段统一使用 ISO `YYYY-MM-DD`；内存中使用无时区的交易日期类型，落盘不得混用 `YYYYMMDD` 与 ISO 格式。
- 所有行情均代表单一 `ts_code` 的日线记录，并按 `trade_date` 严格升序。
- 数值计算使用浮点类型；展示层负责格式化，不改变底层精度。
- 缺失值落盘使用空值，不使用 0、`-` 等替代真实缺失。
- 枚举值统一使用小写英文；字段名统一 snake_case。
- 价格/成交单位保持数据源原始定义，并在数据源元数据中记录。若执行单位换算，必须保存换算规则；不得在同一数据集中混用单位。

## 2. 标准行情数据 `MarketDataFrame`

主键：`ts_code + trade_date`。

| 字段 | 类型 | 必填 | 约束与语义 |
| --- | --- | --- | --- |
| `ts_code` | string | 是 | Tushare 风格证券代码，如代码与交易所后缀；单个数据集只能包含一个代码 |
| `trade_date` | date | 是 | 真实交易记录日期，严格升序且不得重复 |
| `open` | float | 是 | 当日开盘价，必须为正 |
| `high` | float | 是 | 当日最高价，必须为正，且不低于 open/close/low |
| `low` | float | 是 | 当日最低价，必须为正，且不高于 open/close/high |
| `close` | float | 是 | 当日收盘价，必须为正；预测目标字段 |
| `vol` | float | 是 | 成交量，必须非负；单位由 source metadata 声明 |
| `amount` | float | 是 | 成交额，必须非负；单位由 source metadata 声明 |

标准字段顺序固定为：`ts_code, trade_date, open, high, low, close, vol, amount`。

## 4. 数据质量报告 `DataQualityReport`

阶段 2 的报告针对导入/获取后的标准字段生成。CSV 去重前先生成源质量报告，因此可追溯重复日期；缓存活动数据按日期唯一。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `total_rows` | int | 质量检查输入总行数 |
| `start_date` / `end_date` | date/null | 可解析交易日期的起止范围 |
| `duplicate_dates` | int | 重复主键中除首条外的记录数 |
| `duplicate_date_values` | array[date] | 出现重复的交易日期 |
| `missing_values` | object | 八个标准字段各自的缺失数量 |
| `non_positive_prices` | object | open/high/low/close 各自小于等于 0 的数量 |
| `negative_volume` | int | vol 小于 0 的记录数 |
| `negative_amount` | int | amount 小于 0 的记录数 |
| `ohlc_logic_errors` | object | 六类 OHLC 关系错误及涉及的总行数 |
| `passed` | bool | 是否不存在上述重复、缺失、数值和 OHLC 异常 |
| `warnings` | array[string] | 面向用户的非致命质量摘要 |

OHLC 必须同时满足：`high >= open`、`high >= close`、`high >= low`、`low <= open`、`low <= close`、`low <= high`。质量检查只记录事实，不伪造、填充或自动修改异常价格。重复日期在进入缓存前按稳定排序保留输入中的最后一条，并记录移除数量。
## 5. 时间划分 `SplitBoundaries`

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `train_ratio` | float | 默认 0.70 |
| `val_ratio` | float | 默认 0.15 |
| `test_ratio` | float | 默认 0.15，三者之和为 1 |
| `train_target_start/end` | date | 训练集目标日期范围 |
| `val_target_start/end` | date | 验证集目标日期范围，晚于训练集 |
| `test_target_start/end` | date | 测试集目标日期范围，晚于验证集 |
| `train_target_count` | int | 训练目标数量 |
| `val_target_count` | int | 验证目标数量 |
| `test_target_count` | int | 测试目标数量 |
| `overlap_count` | int | 必须为 0 |
| `shuffle` | bool | 必须为 false |

划分比例作用于可用目标日期的时间序列。具体整数边界采用“前两段向下取整、余数归测试集”的固定策略，后续实现和测试不得因模型不同而改变。

## 7. 滑动窗口样本 `WindowSample`

| 字段 | 类型/形状 | 说明 |
| --- | --- | --- |
| `sample_id` | string | 样本唯一标识 |
| `ts_code` | string | 股票代码 |
| `split` | enum | `train` / `val` / `test` |
| `feature_set` | enum | `univariate_close` / `multivariate_ohlcva` |
| `feature_columns` | array[string] | 单变量 `[close]`；多变量 `[open, high, low, close, vol, amount]` |
| `window_size` | int | 默认 60，可实验取 20/30/60 |
| `input_start_date` | date | 输入窗口首个交易日期 |
| `input_end_date` | date | 输入窗口最后交易日期，即 t 日 |
| `target_date` | date | 目标真实交易日期，即 t+1；必须晚于 input_end_date |
| `x` | float array | 形状 `[window_size, feature_count]` |
| `y` | float | target_date 的 close，可为缩放值但必须标记 |
| `previous_close` | float | input_end_date 的 close，用于 Naive 和 DA |
| `is_scaled` | bool | x/y 是否缩放 |
| `gap_status` | enum | `valid` / `dropped_unverified_gap`；仅 valid 进入模型 |

验证/测试样本的输入窗口可跨越前一区间边界，但 `split` 由 target_date 决定。

## 8. 特征集定义

| `feature_set` | 输入列（顺序固定） | 目标 |
| --- | --- | --- |
| `univariate_close` | `close` | 下一真实交易日 `close` |
| `multivariate_ohlcva` | `open, high, low, close, vol, amount` | 下一真实交易日 `close` |

特征顺序属于模型兼容性元数据，加载模型时必须完全一致。

## 9. 模型定义与枚举

| `model_name` | `model_family` | 输入 | 是否训练 |
| --- | --- | --- | --- |
| `naive` | `baseline` | close | 否 |
| `ma5` | `baseline` | close | 否 |
| `ma10` | `baseline` | close | 否 |
| `ma20` | `baseline` | close | 否 |
| `ses` | `baseline` | close | 是/拟合 |
| `arima` | `baseline` | close | 是/拟合 |
| `lstm_univariate` | `lstm` | close | 是 |
| `lstm_multivariate` | `lstm` | open/high/low/close/vol/amount | 是 |

主对比允许：`naive, ma5, ma10, ma20, ses, arima, lstm_univariate`。特征消融允许：`lstm_univariate, lstm_multivariate`。

## 10. 统一预测结果 `PredictionFrame`

主键建议：`experiment_id + model_id + ts_code + target_date`。所有 Naive、MA5、MA10、MA20、SES、ARIMA、LSTM 必须输出同一字段集合。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `experiment_id` | string | 是 | 实验标识 |
| `model_id` | string | 是 | 模型实例标识 |
| `model_name` | enum | 是 | 见模型枚举 |
| `model_family` | enum | 是 | `baseline` / `lstm` |
| `feature_set` | enum | 是 | 见特征集定义；所有传统基线为 `univariate_close` |
| `ts_code` | string | 是 | 股票代码 |
| `split` | enum | 是 | 评价记录为 `val` / `test`；未来推断可为 `forecast` |
| `forecast_origin_date` | date | 是 | 可用信息截止日 t，等同 previous_trade_date |
| `target_date` | date | 是 | 被预测的下一真实交易日 t+1 |
| `previous_trade_date` | date | 是 | target_date 前一个有效交易记录日期 |
| `previous_close` | float | 是 | previous_trade_date 的 close |
| `actual` | float/null | 条件必填 | 回测评价必须有 target_date 的真实 close；未来推断可为空 |
| `predicted` | float | 是 | 反归一化后的价格预测值 |
| `error` | float/null | 条件必填 | `predicted - actual` |
| `abs_error` | float/null | 条件必填 | `abs(error)` |
| `squared_error` | float/null | 条件必填 | `error²` |
| `actual_direction` | int/null | 条件必填 | `sign(actual - previous_close)`，取 -1/0/1 |
| `predicted_direction` | int | 是 | `sign(predicted - previous_close)`，取 -1/0/1 |
| `direction_correct` | bool/null | 条件必填 | 两个方向符号是否一致 |
| `generated_at` | datetime | 是 | 预测记录生成时间 |

“条件必填”指回测与指标计算时必填；若 `actual` 为空，则误差、实际方向和正确性必须为空，不得填 0。

| `experiment_id` | string | 实验标识 |
| `model_id` | string | 模型标识 |
| `epoch` | int | 从 1 开始 |
| `train_loss` | float | 训练集 MSE |
| `val_loss` | float | 验证集 MSE |

## 17. 存储格式约定

- 标准行情缓存优先使用 Parquet；缺少引擎或格式不满足时回退 UTF-8 CSV。
- 每个股票使用安全化文件名，并以 `*.cache.json` 记录当前活动格式、日期范围、行数与质量报告文件。
- 行情保存、显式覆盖和增量更新使用同目录临时文件与原子替换；默认保存拒绝覆盖已有缓存。
- CSV 是离线交换格式；日期落盘统一为 `YYYY-MM-DD`，读取后恢复为无时区日期类型。
- 配置使用 YAML；机器清单、指标、质量与对齐报告使用 JSON。
- 模型权重使用 `.pt` state_dict；缩放器使用 Joblib；图表导出按阶段 8 要求执行。
- 所有 manifest 中路径均相对项目配置的 data/artifact 根目录，不保存用户绝对路径或固定盘符。
