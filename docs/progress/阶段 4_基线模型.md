# 阶段 4：Naive、MA、SES 与 ARIMA 基线模型

- 日期：2026-09-16
- 状态：验收通过；未进入阶段 5
- 执行方式：单 Agent 串行，未创建或委派子 Agent

## 完成内容

1. 定义统一 `ForecastModel`：`fit`、`predict`、`get_params` 和 `model_name`。
2. 统一输出字段：`target_date、previous_close、actual、predicted、model_name`。
3. 实现 Naive、MA5、MA10、MA20、SES、ARIMA 六种单变量基线。
4. `fit` 只接受阶段 3 的训练分区；预测时校验训练日期与 close 前缀一致。
5. 实现滚动一步和静态多步协议；正式比较默认滚动一步。
6. 滚动协议严格先预测再使用本日 actual 更新，SES/ARIMA 参数不在验证或测试区间重估。
7. 实现六模型统一执行、字段校验和 target_date/actual/previous_close 对齐检查。
8. 支持权威交易日历检查训练起点至最后目标日的缺口、日历覆盖范围和非预期日期。
9. 处理数据不足、非有限值、未拟合、无效参数、统计模型拟合失败与日期异常。
10. 新增手算序列、稳定序列、未来值篡改、异常和日期对齐测试及说明文档。

## 关键结论

- 六种模型输出字段、目标日期、actual 和 previous_close 完全一致。
- 修改首个目标日及未来真实值不会改变首个预测，未来数据泄漏测试通过。
- Naive/MA 手算结果、SES/ARIMA 有限预测、ARIMA 明确失败错误、两种协议差异和日期异常均有测试。
