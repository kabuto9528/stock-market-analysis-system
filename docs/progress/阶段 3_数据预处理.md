# 阶段 3：数据清洗、时间划分与滑动窗口

- 日期：2026-09-16
- 状态：验收通过；未进入阶段 4
- 执行方式：单 Agent 串行，未创建或委派子 Agent

## 完成内容

1. 新增行情清洗器：数值转换、稳定升序、日期去重、仅前向填充、开头缺失删除及审计报告。
2. 新增 70%/15%/15% 连续时间划分，保存三个分区日期/位置边界并检查日期互斥。
3. 新增仅接受 `TemporalSplit` 的 ScalerManager，固定只在训练分区拟合特征和目标缩放器。
4. Scaler 以带 SHA-256 完整性校验的 JSON 保存特征顺序、目标列、参数和训练日期区间。
5. 新增单变量与六变量滑动窗口，保存 target_date、previous_close、原始目标和输入起止日期。
6. 验证/测试首个目标可读取前一区间末尾上下文，但强制 `input_end_date < target_date`。
7. 新增 PyTorch Dataset、可复现 DataLoader 及验证/测试禁止 shuffle 约束。
8. 新增数据处理说明与阶段 3 论文素材卡。

## 关键结论

- 验证/测试极端值不会改变训练 Scaler 的最小值和最大值。
- 三组目标日期不重叠，所有目标日期严格晚于输入窗口结束日期。
- 单变量、多变量形状、跨边界上下文、安全加载和反归一化均有自动化测试。
