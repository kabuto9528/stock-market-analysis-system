## 实际完成

1. 提炼用户、功能需求、非功能需求、范围外事项和异常场景。
2. 确定表现层、业务服务层、数据与模型访问层，以及可测试算法内核的职责边界。
3. 设计数据获取、缓存、清洗、样本构造、基线、LSTM、回测、实验和可视化模块。
4. 固定预测任务为截至 t 日预测 t+1 真实交易日 close。
5. 固定单变量 close 和多变量 open/high/low/close/vol/amount 两套 LSTM 输入。
6. 定义七类模型统一 PredictionFrame、对齐报告、指标、模型与实验元数据。
7. 固定 70/15/15 顺序划分、训练集 scaler、验证早停、测试隔离和公共日期规则。
8. 固定 RMSE、MAE、R²、DA 三分类和平盘规则、相对 Naive RMSE 提升率。
9. 设计 Streamlit 页面、显式训练操作、配置/产物目录和离线答辩流程。
10. 将开题报告的 Python 3.10 实现表述按项目规范统一升级为 Python 3.12，并在需求文档记录差异。

## 接口与数据契约

- 标准行情字段：`ts_code, trade_date, open, high, low, close, vol, amount`。
- 样本约束：`input_end_date < target_date`，previous_close 为目标日前一真实交易日 close。
- 统一预测结果以 `experiment_id + model_id + ts_code + target_date` 标识。
- 对齐键：`ts_code + target_date + split`；策略：公共日期交集。
- 主对比：六种单变量基线与单变量 LSTM；多变量 LSTM 仅进入消融组。
