# 系统使用说明

## 1. 启动与定位

本系统用于股票时间序列教学、科研和毕业答辩演示。预测任务为：使用截至第 t 个交易日的数据，预测第 t+1 个交易日收盘价。

```powershell
cd D:\1graduation_project
.\.venv\Scripts\Activate.ps1
python -m streamlit run app.py
```

浏览器默认打开本机 Streamlit 地址。页面刷新不会自动获取数据或训练模型。

## 2. 数据获取

### 2.1 Tushare

1. 在 `.env` 中设置 `TUSHARE_TOKEN`，不要把 Token 写入源码或 YAML。
2. 输入 `600000.SH`、`000001.SZ` 等标准代码和起止日期。
3. 点击“从 Tushare 获取”。可勾选写入本地缓存。

Token 缺失、网络异常、接口无权限或返回空数据时，页面只显示中文业务错误，不展示完整堆栈。

### 2.2 CSV

CSV 必须包含：`ts_code、trade_date、open、high、low、close、vol、amount`。推荐 UTF-8 编码。可填写预期股票代码进行一致性校验，并可将导入结果保存到本地缓存。

### 2.3 本地缓存与离线演示

“本地缓存”可在无网络时加载以前保存的行情。“离线演示”使用固定小型测试样例，仅用于演示页面和链路，不是正式行情结论。缓存位于配置声明的 `data/cache/`。

加载成功后页面显示最近 30 行数据与质量报告，包括行数、日期范围、重复日期、异常成交量/成交额及警告。

## 3. 数据分析

数据分析页自动使用当前会话中的行情，提供：

- 日线 K 线图；
- 收盘价及 MA5、MA10、MA20；
- 成交量走势；
- 日收益率分布；
- open、high、low、close、vol、amount 相关性热力图。

全部图表使用 Plotly，可缩放、悬停查看和导出图片。计算发生在 service 层，页面只负责展示。

## 4. 模型训练

可配置单变量（仅 close）或多变量（OHLC、vol、amount）LSTM，以及窗口、隐藏单元、层数、Dropout、Batch Size、学习率、最大 Epoch、Patience、随机种子和设备。

训练必须点击“开始训练”按钮。系统按 70%/15%/15% 顺序划分，Scaler 只在训练集拟合，验证集只用于 Early Stopping，测试集只在最佳模型固定后评价一次。训练期间显示 Epoch 进度及训练/验证损失，完成后显示最优 Epoch、最低验证损失、耗时和设备。

交互训练产物保存到 `artifacts/experiments/<experiment_id>/`，包括模型、Scaler、训练历史、指标、逐日预测、日期对齐和下一交易日预测。交互结果统一标记为 `test`。

## 5. 预测分析

选择已有实验与模型后，可查看：

- 测试集真实/预测曲线；
- 逐日预测误差；
- RMSE、MAE、DA、相对 Naive RMSE 提升率；
- 已保存的下一交易日预测。

历史实验未保存下一日预测时，可用当前数据加载实验中的模型和 Scaler实时计算。系统会校验股票代码、特征列、输入维度、窗口与历史长度；不匹配时拒绝预测并给出中文提示。下一日期按工作日估算，节假日应以交易所日历为准。

## 6. 模型对比与下载

模型对比页展示 Naive、MA5/10/20、SES、ARIMA 和当前实验的 LSTM。若选择同股票、同区间、同划分的另一特征模式实验，可合并展示单变量与多变量 LSTM。

主比较只允许传统单变量模型与单变量 LSTM；多变量 LSTM 属于特征消融，应单独讨论。模型排序依据 DA、相对提升率和 RMSE，R² 仅作价格水平拟合度参考，不用于排名。

页面可下载模型指标 CSV 和逐日预测 CSV。下载内容来自已保存实验产物，不在页面重复计算评价算法。

## 7. 常见问题

- **没有 Token**：使用 CSV、本地缓存或离线演示。
- **数据不足**：增加历史区间或减小窗口；训练集行数必须大于窗口，验证/测试也要有目标样本。
- **模型不存在**：先训练模型，或选择包含 `selected_lstm.pt` 与 Scaler 的完整实验。
- **配置不匹配**：加载与模型股票、特征和窗口一致的数据。
- **训练失败**：检查参数、数据质量和 CUDA 可用性；可切换为 CPU。
- **刷新后是否重训**：不会。只有按钮提交会调用训练服务，最近上下文保存在 session state。

## 8. 风险声明

本系统仅用于教学与科研演示，不构成投资建议、收益承诺或交易依据。股票市场具有高波动和不确定性，使用者应独立判断并自行承担风险。
