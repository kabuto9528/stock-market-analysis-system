# 系统使用说明

## 1. 启动

```powershell
Set-Location <项目目录>
.\.venv\Scripts\Activate.ps1
python -m streamlit run app.py
```

系统使用截至第 t 日的数据预测第 t+1 交易日收盘价。页面刷新不会自动获取数据或训练模型。

## 2. 数据获取

- **Tushare**：从 `.env` 读取 Token；输入标准股票代码和日期，点击按钮后才联网。
- **CSV**：必须包含 `ts_code、trade_date、open、high、low、close、vol、amount`。
- **本地缓存**：读取以前保存的行情，不访问网络。
- **离线演示**：读取 `demo/offline_market.csv`，固定小样例仅用于演示和测试。

加载期间显示状态提示；成功后显示最近 30 行和质量报告。空数据、缺字段、非法代码、Token 缺失、网络异常和接口空结果均给出中文错误。

## 3. 数据分析

展示日线 K 线、MA5/10/20、成交量、日收益率分布和特征相关性。图表由 service 层生成，页面只展示。Plotly 支持缩放、悬停和图片导出。

## 4. 模型训练

1. 选择单变量（仅 close）或多变量特征。
2. 设置窗口、隐藏单元、层数、Dropout、Batch Size、学习率、Epoch、Patience、种子和设备。
3. 点击“开始训练”。只有表单提交才调用训练服务。
4. 查看 Epoch 进度、训练/验证损失、最佳 Epoch、最低验证损失、耗时和设备。

系统顺序划分 70%/15%/15%，Scaler 只拟合训练集，验证集用于 Early Stopping，测试集在最佳模型固定后评价一次。交互产物统一标记 `test`。

## 5. 预测分析

选择实验后查看测试集真实/预测曲线、逐日误差、RMSE、MAE、DA、相对 Naive RMSE 提升率和下一交易日估算。加载预训练模型时校验股票代码、特征列、输入维度、窗口长度、Scaler 和历史长度；耗时加载显示状态提示。

下一日期按下一工作日估算，未内置交易所节假日日历，现场应明确此限制。

## 6. 模型对比

主表只比较 Naive、MA、SES、ARIMA 与单变量 LSTM；多变量 LSTM 只进入特征消融。所有模型按公共测试目标日期计算指标。R² 不参与排名。

## 7. 推荐离线答辩操作

1. 数据获取 → 离线演示 → 加载样例。
2. 数据分析 → 依次展示 K 线、均线和相关性。
3. 预测分析 → 选择 `offline_demo_stage9`，展示已有预测。
4. 模型对比 → 展示指标、DA 与相对提升率，并解释负结果。
5. 如需证明可训练，只展示训练页参数和按钮，不在现场运行长训练。

## 8. 结果目录

- 普通实验：`artifacts/experiments/<experiment_id>/`
- 正式实验：`artifacts/stage8/formal_20260916_1805/`
- 离线交付副本：`demo/offline_demo_stage9/`

每个完整实验含配置、记录、指标、逐日预测、日期对齐、模型、Scaler 和训练历史，可由 experiment_id 追溯。
