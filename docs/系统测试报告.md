- `test_naive_uses_previous_real_close_on_hand_calculable_sequence`：Naive 使用目标日前已实现 close。

## 7. 异常与降级测试

| 场景 | 测试结果 |
| --- | --- |
| 空 CSV/仅表头 | 拒绝并给出空数据错误 |
| 缺字段/非法数值/非法日期 | 拒绝并指出字段或位置 |
| 样本不足 | 训练服务给出增加历史或减小窗口提示 |
| Token 缺失 | 不联网，提示使用 CSV |
| 无网络 | mock 请求异常转换为 TushareNetworkError |
| 非法股票代码 | 在网络调用前拒绝 |
| 模型不存在 | 友好错误 |
| 模型/股票/特征/窗口不匹配 | 拒绝加载 |
| ARIMA 拟合失败 | 转换为明确基线错误 |
| 缓存 Parquet 不可用 | 自动回退 CSV |
