## 可用于论文的工程结论

1. 行情先统一数值类型、按交易日期稳定升序并删除重复日期，避免时序次序和同日冲突影响样本。
2. 缺失值仅使用历史记录前向填充，开头无法填充的记录直接删除并形成可追溯报告，禁止后向填充引入未来信息。
3. 数据以连续时间片按 70%/15%/15% 划分，训练、验证、测试日期及窗口目标日期均两两互斥。
4. Scaler 接口结构上只读取训练分区；验证集和测试集只做 transform，防泄漏测试可检测全量拟合错误。
5. 验证和测试首个目标允许使用前一区间末尾作为历史上下文，但每个输入日期必须严格早于目标日期。
6. 单变量窗口形状为 `(N, 60, 1)`，多变量窗口形状为 `(N, 60, 6)`，并保存目标日期、原始目标和上一交易日收盘价。
7. 缩放器使用带完整性校验的 JSON 保存列顺序、目标列、参数和训练日期区间，支持安全加载与目标反归一化。

## 答辩口径

- 为什么不能随机划分：随机划分会让未来日期进入训练集，破坏真实预测顺序并产生泄漏。
- 为什么只前向填充：后向填充会用未来价格修补过去记录；前向填充只使用当时已经可见的信息。
- 为什么验证首个窗口能读取训练末尾：历史上下文早于验证目标，不改变目标归属，也不参与重新拟合 Scaler。
- 为什么默认 60：约覆盖 3 个交易月，在时序信息长度和可用训练样本数之间折中；最终只通过验证集做受控比较。
- 如何证明 Scaler 无泄漏：测试把验证/测试值设置为极端大值，训练 Scaler 最大值仍只能来自训练集。
