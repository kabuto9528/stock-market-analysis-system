# 素材卡：阶段 0 需求分析与架构设计

## 基本信息

- 阶段：0
- 日期：2026-09-15
- 项目：基于 LSTM 神经网络的股票价格预测系统
- 实现环境：Python 3.12
- 素材性质：设计结论，不包含模型实验结果
- 依据：`开题报告.md`、项目级开发规范、阶段 0 验收要求

## 可用于论文的设计结论

1. 系统研究对象为沪深 A 股日线量价数据，任务固定为使用截至第 t 个交易日的信息预测第 t+1 个真实交易日收盘价。
2. 单变量实验仅使用 close；多变量实验使用 open、high、low、close、vol、amount，二者目标均为下一交易日 close。
3. 系统采用表现层、业务服务层、数据与模型访问层的分层结构，算法内核与 Streamlit 页面解耦，便于测试、复现和离线演示。
4. 主对比包括 Naive、MA5、MA10、MA20、SES、ARIMA 和单变量 LSTM；多变量 LSTM 仅用于与单变量 LSTM 的特征消融，不混入传统模型主对比。
5. 数据按目标日期顺序划分为 70%/15%/15%，不随机打乱；MinMaxScaler 只在训练集拟合；验证集用于调参与早停；测试集只用于最终评价。
6. 所有模型按公共 target_date 比较，并统一保留 previous_close、actual、predicted 和方向字段，以保证误差与 DA 可复算。
7. 评价指标为 RMSE、MAE、R²、DA 和相对 Naive RMSE 提升率。R²仅表示价格水平拟合程度，模型优劣主要结合 DA 与相对提升率判断。
8. 系统通过 experiment_id 保存配置、数据指纹、种子、模型、逐日预测、指标、耗时和图表，实现结果追溯。

## 答辩口径

- 为什么预测下一交易日 close：目标明确、可由日线数据监督构造，适合比较传统时序方法与 LSTM。
- 为什么窗口默认 60：约覆盖三个月交易历史，在中期依赖信息和样本数量之间折中，并用 20/30/60 受控验证。
- 为什么不能只看 R²：趋势性价格序列可能产生较高 R²，但不代表相对 Naive 有增益或涨跌方向判断可靠。
- 如何避免泄漏：顺序划分、训练集拟合 scaler、窗口结束早于目标、验证选择、测试隔离、公共日期对齐。
- 如何离线答辩：加载真实本地 CSV、预训练模型和同一 experiment_id 的预生成结果，页面显示数据截止日期。
