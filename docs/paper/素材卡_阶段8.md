# 素材卡：阶段 8 正式实验与论文结果导出

## 阶段结论

- 日期：2026-09-16。
- 正式实验已完成，使用真实 BaoStock 日线数据，正式 run 为 `artifacts/stage8/formal_20260916_1805`。
- 覆盖 4 只股票、4 个行业、2018-01-02 至 2025-12-31，不含合成数据。
- 共生成 72 个可追溯实验目录，并通过逐日预测指标重算和一致性检查。

## 方法描述

1. 参数实验只使用验证集，按窗口→隐藏单元→层数→学习率控制变量选择，锁定窗口 30、hidden_size 128、1 层、学习率 0.01。
2. 主比较只含 Naive、MA5/10/20、SES、ARIMA 与 close 单变量 LSTM；多变量 LSTM 单独作为特征消融。
3. 单/多变量 LSTM 均使用 42、2024、2026 三个固定种子，测试集只在模型和参数固定后评价。
4. 每次实验保存配置、模型、Scaler、训练历史、逐日预测、指标、耗时和种子。
5. 一致性检查从逐日预测重算 RMSE、MAE、R² 和 DA，并核对目标日期、actual、previous_close、种子和测试评价次数。

## 客观结果

- 单变量 LSTM 平均 RMSE 12.2663，高于 Naive 的 4.78791；平均 DA 48.38%，相对 Naive 提升率 -273.01%。
- ARIMA 平均 RMSE 4.78397、平均 DA 50.94%。
- 多变量 LSTM 平均 RMSE 5.90721，但仅在 1/4 股票上提高 DA，改善不稳定。
- 不能声称 LSTM 优于 Naive；R² 未用于模型排名。
